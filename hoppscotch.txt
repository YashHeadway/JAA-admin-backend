====================================================================================================
                        JAA-BACKEND - COMPLETE ADMIN REST API SPECIFICATION
====================================================================================================
Base URL Environment Variable:
  admin_base_url : http://192.168.1.49:5000/api/admin/
  (Localhost fallback: http://localhost:5000/api/admin/)
  token          : Bearer <JWT Token>

All endpoints simply append to <<admin_base_url>>:
  Example: <<admin_base_url>>members -> http://192.168.1.49:5000/api/admin/members

[3.2] Create Committee
----------------------------------------------------------------------------------------------------
Method:   POST
Endpoint: <<admin_base_url>>committee
          (Full URL: http://192.168.1.49:5000/api/admin/committee)

Headers:
  Content-Type:  application/json OR multipart/form-data
  Authorization: Bearer <<token>>

Request Body (Option A - JSON):
{
  "position": "Chairman",
  "members": [
    {
      "memberId": 14
    },
    {
      "memberId": 12
    }
  ]
}

Request Body (Option B - form-data / direct memberId):
  position: test
  memberId: 14   (or comma-separated: 14, 12)

Response (201 Created):
{
  "success": true,
  "status": true,
  "message": "Committee created successfully",
  "data": {
    "id": 12,
    "position": "Chairman",
    "members": [

        "memberId": 14,
